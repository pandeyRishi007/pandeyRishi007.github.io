Rishikesh Pandey: Portfolio

Personal portfolio of a full-stack developer (MCA, Brainware University; 5-month full-stack intern at IBM).

Live: https://adorable-manatee-f3abfe.netlify.app

Features
Responsive single-page site with a dark theme
Animated terminal intro
Project cards generated from one JavaScript array
Skills, experience, education and certifications with credential links
Tech

HTML, CSS and vanilla JavaScript in a single index.html. No build step and no dependencies.

Run locally

Clone the repo and open index.html in your browser.

Add a project

Add an entry to the projects array at the bottom of index.html:

js
{ name: "Project", date: "Jan 2026", tag: "GitHub", tagType: "live",
  gh: "https://github.com/...", live: "https://...", // both optional
  stack: "React · Node.js", desc: "What it does.", org: "Solo Project" }
